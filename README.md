# 🎵 Music Streaming Analytics

A full-stack Music Streaming Analytics project that provides insights into music streaming data using a modern frontend, FastAPI backend, and SQL database integration.

---

# 📌 Project Overview

This project is designed to analyze and visualize music streaming data. It includes:

* Interactive frontend interface
* FastAPI backend APIs
* SQL database integration
* Analytics and reporting features
* Structured project documentation

The system helps users explore streaming trends, track statistics, and music-related insights efficiently.

# 🚀 Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/MusicStreamingAnalytics.git
```

```bash
cd MusicStreamingAnalytics_Final
```

---

## 2️⃣ Install Python Dependencies

Move to backend folder:

```bash
cd music_streaming_backend
```

Install required packages:

```bash
pip install -r requirements.txt
```

---

## 3️⃣ Run the Backend Server

```bash
uvicorn main:app --reload
```

Backend will start on:

```bash
http://127.0.0.1:8000
```

---

## 4️⃣ Open Frontend

Open:

```bash
frontend/index.html
```

in your browser.
